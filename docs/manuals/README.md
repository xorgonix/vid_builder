# vid-build 0.02 — Manuals

*Idea to finished film, one visible change at a time.*

vid-build is a **local-first video development studio**: it takes one idea
through develop → outline → see it → block it → generate it → review it →
assemble it, and helps you decide where to run the expensive parts. Everything
runs on your machine — a single SQLite database, a folder of media, and whatever
models you already run in LM Studio and ComfyUI.

The documentation is split into focused manuals:

| Manual | Read it when you want to… |
|---|---|
| [Getting started](01-getting-started.md) | install, sign in, and learn the concepts and the shell. |
| [Creative development](02-creative-development.md) | turn an idea into a brief, outline, beats, blocking, continuity and an animatic. |
| [Production and delivery](03-production-and-delivery.md) | import workflows, generate, make duration videos, review, edit, export and plan compute. |
| [Operations and administration](04-operations-and-admin.md) | manage accounts and workspaces, back up, use LAN/offline, configure and troubleshoot. |
| [Guided tours](05-guided-tours.md) | watch the software drive the real interface and explain each step. |

New here? Read **Getting started**, then open **Guided tours** in the app
(`/tutorials`) and run *Create a workspace and project*.
